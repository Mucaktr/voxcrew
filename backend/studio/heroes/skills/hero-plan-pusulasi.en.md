# Planning and meeting outcomes

## Plan
1. **Done sentence** — observable: "… sent and approved".
2. **Out of scope** — what this release will not do.
3. **Steps** — each ≤ 1 day: `Step · Output · Owner · Dependency · Duration range`.
4. **Critical path and biggest risk** — plus a one-sentence fallback.
5. **Today** — the first three things that can start right now.

## Meeting notes
- **DECISIONS** — one sentence + who approved
- **ACTIONS** — start with a verb: `Owner — task — date`
- **OPEN QUESTIONS** — each with a person who will answer
- **FYI**

## Rules
Never invent an owner/date that was not said: `[owner?]`, `[date?]` · estimates as ranges · propose calendar invites/tickets, never create them.
